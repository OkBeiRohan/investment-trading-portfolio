## Data Structure

```typescript
// nifty50-constituents.json schema
interface Nifty50Constituent {
  companyName: string;
  industry: string;       // Sector from Upstox/NSE
  symbol: string;         // NSE trading symbol
  series: string;         // EQ
  isin: string;           // ISIN code
  instrumentKey: string;  // Upstox instrument key (NSE_EQ|ISIN)
  weightPct: number;      // NSE free-float market cap weight (%)
}
```

## Usage in Feature Computation

### Point-in-Time Constituents

```typescript
import { ConstituentManagerService } from './constituent-manager.service';

const manager = new ConstituentManagerService();

// Get constituents at a historical date
const before = manager.getConstituentsAtTimestamp(new Date('2024-09-29'));
const after = manager.getConstituentsAtTimestamp(new Date('2024-09-30'));
```

### Weight-Aware Breadth Computation

```typescript
// Equal-weight breadth (traditional)
const equalBreadth = stocksAboveVwap.length / 50;

// Cap-weighted breadth (new)
const weightedBreadth = stocksAboveVwap.reduce(
  (sum, s) => sum + manager.getWeightBySymbol(s),
  0,
) / 100;

// Divergence signal (concentration risk)
const divergence = equalBreadth - weightedBreadth;
```

### Top-N Contribution

```typescript
const top5Weight = manager.getTopNWeight(5);  // ~37.55%
const sectorWeights = manager.getSectorWeights();
```
