## 🔑 Key Concepts

### Option Payoffs (at Expiry)

| Position       | Max Profit       | Max Loss         | Breakeven        |
| -------------- | ---------------- | ---------------- | ---------------- |
| **Long Call**  | Unlimited        | Premium paid     | Strike + Premium |
| **Short Call** | Premium received | Unlimited        | Strike + Premium |
| **Long Put**   | Strike - Premium | Premium paid     | Strike - Premium |
| **Short Put**  | Premium received | Strike - Premium | Strike - Premium |

### The Greeks Summary

| Greek         | Measures               | Call Value | Put Value | Strategy            |
| ------------- | ---------------------- | ---------- | --------- | ------------------- |
| **Delta (Δ)** | Price sensitivity      | 0 to +1    | 0 to -1   | Directional hedging |
| **Gamma (Γ)** | Delta change rate      | Always +   | Always +  | Scalping, hedging   |
| **Theta (θ)** | Time decay             | Usually -  | Usually - | Income (selling)    |
| **Vega (ν)**  | Volatility sensitivity | Always +   | Always +  | IV trading          |

### Delta Interpretation

| Delta    | Moneyness | Probability of ITM | Example                        |
| -------- | --------- | ------------------ | ------------------------------ |
| **0.10** | Deep OTM  | 10%                | Nifty 18000 CE when spot=17500 |
| **0.30** | OTM       | 30%                | Nifty 17700 CE when spot=17500 |
| **0.50** | ATM       | 50%                | Nifty 17500 CE when spot=17500 |
| **0.70** | ITM       | 70%                | Nifty 17300 CE when spot=17500 |
| **0.90** | Deep ITM  | 90%                | Nifty 17000 CE when spot=17500 |

### Volatility Regimes

| IV Percentile | Regime         | Strategy                             |
| ------------- | -------------- | ------------------------------------ |
| **0-20%**     | Low volatility | Buy options (straddles, strangles)   |
| **20-50%**    | Normal         | Directional trades                   |
| **50-80%**    | Elevated       | Sell options (iron condors, spreads) |
| **80-100%**   | Very high      | Sell premium aggressively            |

## 💡 Practical Applications

### For Directional Trading

```
Bullish View → Buy Call (limited risk)
Moderate Bullish → Bull Call Spread (reduce cost)
Very Bullish → Sell Put (income + obligation)

Bearish View → Buy Put (limited risk)
Moderate Bearish → Bear Put Spread
Very Bearish → Sell Call (limited profit)
```

### For Income Generation (Theta Strategies)

```
High IV → Sell ATM/OTM options
Collect theta daily (time decay)
Hedge with far OTM options (defined risk)

Example: Iron Condor
- Sell 17400 CE + 17600 PE
- Buy 17300 CE + 17700 PE
- Profit if Nifty stays in 17400-17600 range
```

### For Volatility Trading

```
Low IV + Expecting Event → Buy Straddle
(RBI policy, Budget, Election results)

High IV + Event Passed → Sell Straddle
(IV crush post-earnings)
```

### For Hedging Equity Portfolio

```
Portfolio Value: ₹50L
Nifty Spot: 17500
Delta: -28 (need protection)

Hedge: Buy 1 lot Nifty 17500 PE (delta=-0.5)
- Lot size: 50
- Portfolio delta reduced by: 50 × -0.5 = -25
```

## 📊 Options Calculator (Black-Scholes)

### Input Parameters

- **Spot Price (S)**: Current underlying price
- **Strike Price (K)**: Option strike
- **Time to Expiry (T)**: Days/365
- **Volatility (σ)**: Annualized IV (e.g., 0.15 = 15%)
- **Risk-Free Rate (r)**: 10-year G-Sec yield (e.g., 0.07)

### Black-Scholes Formula (simplified)

```
Call Premium = S × N(d1) - K × e^(-rT) × N(d2)
Put Premium = K × e^(-rT) × N(-d2) - S × N(-d1)

where:
d1 = [ln(S/K) + (r + σ²/2) × T] / (σ × √T)
d2 = d1 - σ × √T
N() = Cumulative normal distribution
```

**Note:** Indian options use **Black-76 model** (futures-based) instead of Black-Scholes.

## ⚠️ Common Mistakes

1. **Selling Naked Options**: Unlimited risk (margin calls, account wipe-out)
2. **Ignoring Volatility**: Buying expensive options (high IV) → IV crush
3. **Holding Till Expiry**: Gamma risk (sharp delta changes), slippage
4. **Overleveraging**: Using max margin → one bad day = blown account
5. **Not Managing Greeks**: Unaware of theta decay or vega risk
6. **Physical Settlement Confusion**: Forced to take delivery if ITM (post-2019 rule)

## 📈 Real-World Example (Case Study)

**Scenario:** Nifty at 17500 on 20-Jan-2026, expecting Budget rally on 1-Feb.

**Strategy:** Long 17500 Straddle (buy call + put)

- **Call Premium:** ₹150
- **Put Premium:** ₹140
- **Total Cost:** ₹290 per lot
- **Lot Size:** 50
- **Total Investment:** ₹14,500

**Greeks at Entry:**

- Delta: ~0 (delta-neutral)
- Gamma: +0.02 (high sensitivity)
- Theta: -₹500/day (decaying fast)
- Vega: +8 (benefits from IV rise)

**Outcome (1-Feb, Post Budget):**

- Nifty moves to 18000 (+500 points)
- Call becomes 18000-17500 = 500 ITM
- Put expires worthless
- Profit: (500 - 290) × 50 = ₹10,500 (~72% return)

**If No Move (17500 on 1-Feb):**

- Both expire worthless
- Loss: ₹14,500 (100% loss)

**Risk/Reward:** High risk, high reward (binary outcome).
