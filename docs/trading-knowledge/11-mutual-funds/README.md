## 📖 Overview

This comprehensive 32-chapter module is your complete guide to mutual fund investing in India. It starts with personal finance fundamentals (time value of money, retirement planning), progresses through mutual fund types (equity, debt, hybrid, index, ETFs), and culminates in portfolio construction and performance analysis.

You'll learn to decode fact sheets, compare expense ratios (direct vs regular plans), measure risk-adjusted returns (Sharpe, Sortino, beta), and build goal-based portfolios. The module covers critical concepts like NAV calculation, rolling returns, asset allocation, and macro-economic factors affecting markets.

Whether you're a salaried employee planning retirement or an investor evaluating fund performance, this module provides the analytical framework to make informed decisions. You'll move beyond past returns to understand risk metrics, fund manager quality, and portfolio diversification.

## 🔑 Key Concepts

### NAV Calculation

```
NAV (Net Asset Value) = (Total Assets - Total Liabilities) / Total Units

Example:
- Fund AUM: ₹1,000 Cr (market value of stocks + cash)
- Liabilities: ₹10 Cr (fund expenses payable)
- Total Units: 50 Cr

NAV = (1,000 - 10) / 50 = ₹19.80 per unit
```

**Note:** NAV updated daily (equity) or weekly (debt)

### SIP Return Calculation (XIRR)

**Example: ₹10,000 monthly SIP for 3 years**

| Month    | Investment | Current Value |
| -------- | ---------- | ------------- |
| Jan 2023 | ₹10,000    | ₹14,500       |
| Feb 2023 | ₹10,000    | ₹14,200       |
| ...      | ...        | ...           |
| Dec 2025 | ₹10,000    | ₹10,800       |

**Total Invested:** ₹3,60,000  
**Current Value:** ₹4,50,000  
**XIRR:** 18.5% per annum (use Excel/Google Sheets `XIRR()` function)

### Expense Ratio Impact (Direct vs Regular)

| Plan        | Expense Ratio | ₹10L investment (10Y @ 12% pre-expense) | Final Value |
| ----------- | ------------- | --------------------------------------- | ----------- |
| **Direct**  | 0.5%          | 12% - 0.5% = 11.5% net                  | ₹29.6L      |
| **Regular** | 1.5%          | 12% - 1.5% = 10.5% net                  | ₹27.1L      |

**Difference:** ₹2.5L (25% higher corpus with direct plan!)

### Asset Allocation by Age (Rule of Thumb)

```
Equity % = 100 - Age

Example:
- Age 30 → 70% equity, 30% debt
- Age 50 → 50% equity, 50% debt
- Age 65 → 35% equity, 65% debt (capital preservation)
```

### Risk Metrics Quick Reference

| Metric                 | Formula                                           | Interpretation                         |
| ---------------------- | ------------------------------------------------- | -------------------------------------- |
| **Sharpe Ratio**       | (Return - Risk-free) / Std Dev                    | >1.0 = Good, >2.0 = Excellent          |
| **Sortino Ratio**      | (Return - Risk-free) / Downside Dev               | Focuses on downside risk only          |
| **Beta**               | Covariance(Fund, Benchmark) / Variance(Benchmark) | <1 = Less volatile, >1 = More volatile |
| **Standard Deviation** | √(Variance)                                       | Higher = More volatile                 |
| **Alpha**              | Actual Return - Expected Return (CAPM)            | +ve = Outperformance                   |

## 📊 Quick Reference

### Mutual Fund Categories (SEBI Classification)

**Equity Funds:**

- Large Cap (Top 100 stocks by market cap)
- Mid Cap (101-250 stocks)
- Small Cap (251+ stocks)
- Flexi Cap (Any market cap, no limit)
- Multi Cap (25% each in large/mid/small)
- Sectoral (Banking, IT, Pharma, etc.)
- Thematic (ESG, Consumption, Infrastructure)

**Debt Funds:**

- Liquid (<91 days maturity)
- Overnight (1-day maturity)
- Ultra Short (3-6 months)
- Low Duration (6-12 months)
- Medium Duration (3-4 years)
- Long Duration (>7 years)
- Gilt (Only G-Secs)

**Hybrid Funds:**

- Aggressive (65-80% equity)
- Balanced (40-60% equity)
- Conservative (10-25% equity)
- Arbitrage (Equity arbitrage + debt)

### Tax Treatment (Post-Budget 2024)

| Fund Type                      | Holding Period                 | Tax Rate                  |
| ------------------------------ | ------------------------------ | ------------------------- |
| **Equity Funds** (>65% equity) | <12 months                     | 15% (STCG)                |
|                                | ≥12 months                     | 10% on gains >₹1L (LTCG)  |
| **Debt Funds**                 | Any                            | Slab rate (as per income) |
| **Hybrid Funds** (>65% equity) | Same as equity                 | 15% / 10%                 |
| **Arbitrage Funds**            | Same as equity (tax-efficient) | 15% / 10%                 |

### Direct vs Regular Plan Comparison

| Aspect                     | Direct Plan              | Regular Plan          |
| -------------------------- | ------------------------ | --------------------- |
| **Distributor Commission** | ✅ No (you buy directly) | ❌ Yes (0.5-1% trail) |
| **Expense Ratio**          | 0.5-1.0%                 | 1.5-2.5%              |
| **10Y Returns (₹10L)**     | ₹29.6L                   | ₹27.1L                |
| **NAV**                    | Higher (no commission)   | Lower                 |
| **Advisor Support**        | Self-service             | Yes (but biased)      |

**Verdict:** Direct plans almost always better (unless you need hand-holding)

## ⚠️ Common Mistakes

1. **Chasing past returns:** Last 1Y return ≠ future performance
2. **Buying NFOs (New Fund Offers):** No track record, wait 2-3 years
3. **Not diversifying:** All money in 1-2 funds (concentration risk)
4. **Over-diversifying:** 20+ funds (overlap, unmanageable)
5. **Ignoring expense ratio:** 1% difference = 25% lower corpus over 20 years
6. **Buying regular plans:** Paying 1% annually for no value-add
7. **Stopping SIP in bear markets:** Best returns come from buying low
8. **Not rebalancing:** 70:30 becomes 85:15 after bull run (restore balance)
9. **Investing in sectoral funds long-term:** High volatility, timing risk
10. **Ignoring tax implications:** Redeeming just before LTCG threshold
