## 🔑 Key Concepts

### Candlestick Patterns (Single)

| Pattern           | Signal           | Characteristics                |
| ----------------- | ---------------- | ------------------------------ |
| **Doji**          | Indecision       | Open = Close, small body       |
| **Marubozu**      | Strong trend     | No wicks, large body           |
| **Hammer**        | Bullish reversal | Long lower wick, at support    |
| **Shooting Star** | Bearish reversal | Long upper wick, at resistance |
| **Spinning Top**  | Indecision       | Small body, long wicks         |

### Candlestick Patterns (Multiple)

| Pattern               | Signal           | Formation                               |
| --------------------- | ---------------- | --------------------------------------- |
| **Bullish Engulfing** | Bullish reversal | Green candle engulfs previous red       |
| **Bearish Engulfing** | Bearish reversal | Red candle engulfs previous green       |
| **Piercing Pattern**  | Bullish          | Green closes above 50% of red           |
| **Dark Cloud Cover**  | Bearish          | Red opens above green, closes below 50% |
| **Morning Star**      | Bullish          | 3-candle bottom reversal                |
| **Evening Star**      | Bearish          | 3-candle top reversal                   |

### Indicators

**RSI (Relative Strength Index)**

- **Range**: 0-100
- **Overbought**: >70 (potential sell)
- **Oversold**: <30 (potential buy)
- **Formula**: RSI = 100 - [100 / (1 + RS)]  
  where RS = Avg Gain / Avg Loss

**MACD (Moving Average Convergence Divergence)**

- **Components**: MACD line (12 EMA - 26 EMA), Signal line (9 EMA of MACD)
- **Buy**: MACD crosses above Signal
- **Sell**: MACD crosses below Signal

**Bollinger Bands**

- **Middle**: 20-period SMA
- **Upper**: SMA + 2 × SD
- **Lower**: SMA - 2 × SD
- **Usage**: Price touching lower band = oversold, upper band = overbought

### Fibonacci Retracement Levels

- **23.6%**: Minor correction
- **38.2%**: Moderate retracement (common entry)
- **50.0%**: Psychological level
- **61.8%**: Golden ratio (strongest support/resistance)
- **78.6%**: Deep retracement

## 💡 Practical Applications

### For Intraday Traders

- Use 5-min/15-min candlesticks for entry/exit
- CPR (Central Pivot Range) for daily levels
- RSI for overbought/oversold conditions
- Volume spikes for breakout confirmation

### For Swing Traders

- Daily/Weekly candlesticks for trend identification
- Moving average crossovers (50/200 EMA)
- Fibonacci for pullback entries
- Support/resistance for profit targets

## 📊 Trading Checklist (from Chapter 19)

### Before Entering Trade

- [ ] Identify trend (uptrend, downtrend, sideways)
- [ ] Spot candlestick pattern (bullish/bearish signal)
- [ ] Check for S&R confluence (pattern near support/resistance)
- [ ] Confirm with volume (higher volume = stronger signal)
- [ ] Verify with indicator (RSI not overbought/oversold)
- [ ] Calculate risk/reward (minimum 1:2 ratio)
- [ ] Set stop-loss (below support for long, above resistance for short)

### After Entering Trade

- [ ] Monitor price action (respect or violation of pattern)
- [ ] Trail stop-loss (lock in profits as price moves favorably)
- [ ] Exit at target or if pattern fails
- [ ] Log trade in journal (pattern, reason, outcome)

## ⚠️ Common Mistakes

1. **Ignoring Volume**: Patterns without volume confirmation often fail
2. **Not Using Stop-Loss**: Never trade without defined risk
3. **Chasing Price**: Wait for pattern completion (confirmation candle)
4. **Over-reliance on Indicators**: Use indicators as confirmation, not primary signal
5. **Trading Against Trend**: "Trend is your friend" (don't fight it)
6. **Pattern Bias**: Don't force patterns where none exist
