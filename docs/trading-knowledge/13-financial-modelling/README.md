## 📖 Overview

This advanced module teaches you to build integrated 3-statement financial models (P&L, Balance Sheet, Cash Flow) in Excel for equity valuation. Unlike standalone DCF models, integrated models dynamically link all financial statements, allowing you to project a company's financials 5-10 years into the future and calculate intrinsic value.

You'll learn to fetch historical data, build assumption drivers (revenue growth, margins, capex), create supporting schedules (asset depreciation, debt amortization, reserves), and link everything into projected financials. The final DCF analysis incorporates WACC, terminal value, and sensitivity analysis to arrive at a target price.

This is the skillset used by equity research analysts at investment banks and mutual funds. The module uses a real company example, walking through every Excel formula and logic step. By the end, you'll have a reusable template for valuing any listed company.

## 🔑 Key Concepts

### Integrated Model Structure

```
Assumptions Sheet
    ↓
Revenue Model → P&L Statement
    ↓                ↓
Asset Schedule → Balance Sheet
Debt Schedule  →      ↓
Reserves Schedule → Cash Flow Statement
    ↓
Free Cash Flow (FCFF/FCFE)
    ↓
DCF Valuation → Intrinsic Value
```

**Key Feature:** Changes to assumptions (e.g., revenue growth 10% → 12%) automatically flow through all statements.

### FCFF vs FCFE

| Metric            | Formula                                                 | Used For                         |
| ----------------- | ------------------------------------------------------- | -------------------------------- |
| **FCFF** (Firm)   | EBIT × (1-Tax) + D&A - Capex - Δ WC                     | Enterprise Value (equity + debt) |
| **FCFE** (Equity) | Net Income + D&A - Capex - Δ WC - Debt Repay + New Debt | Equity Value only                |

**Most Common:** FCFF (values entire firm, then subtract net debt to get equity value)

### WACC Calculation

```
WACC = (E/V × Cost of Equity) + (D/V × Cost of Debt × (1 - Tax Rate))

Where:
E = Market value of equity
D = Market value of debt
V = E + D (total value)

Example (Reliance Industries):
- Market Cap (E) = ₹15,00,000 Cr
- Debt (D) = ₹2,00,000 Cr
- Cost of Equity (CAPM) = 12%
- Cost of Debt = 7%
- Tax Rate = 25%

E/V = 15,00,000 / 17,00,000 = 88.2%
D/V = 2,00,000 / 17,00,000 = 11.8%

WACC = (0.882 × 12%) + (0.118 × 7% × 0.75)
     = 10.58% + 0.62%
     = 11.2%
```

### Terminal Value (Gordon Growth Model)

```
Terminal Value = FCF_final × (1 + g) / (WACC - g)

Where:
g = Perpetual growth rate (typically 3-5%, GDP growth rate)

Example:
- Year 10 FCF = ₹5,000 Cr
- WACC = 11.2%
- g = 4%

Terminal Value = 5,000 × 1.04 / (0.112 - 0.04)
               = 5,200 / 0.072
               = ₹72,222 Cr
```

### DCF Valuation Formula

```
Enterprise Value = Σ [FCF_t / (1 + WACC)^t] + Terminal Value / (1 + WACC)^n

Equity Value = Enterprise Value - Net Debt

Price per Share = Equity Value / Shares Outstanding

Example:
- PV of 10-year FCFs = ₹30,000 Cr
- PV of Terminal Value = ₹40,000 Cr
- Enterprise Value = ₹70,000 Cr
- Net Debt = ₹2,000 Cr
- Equity Value = ₹68,000 Cr
- Shares = 640 Cr
- Intrinsic Value = ₹68,000 / 640 = ₹106.25 per share

If trading @ ₹85 → **Undervalued by 25%**
```

## 💡 Practical Applications

### For Analysts

**Equity Research Workflow:**

1. **Company Selection:** Screen for fundamentally strong companies (ROE >15%, consistent growth)
2. **Historical Analysis:** Download 5Y financials from annual reports/Screener.in
3. **Model Building:** Build integrated 3-statement model with assumptions
4. **Projections:** Forecast 10 years (conservative, base, aggressive scenarios)
5. **Valuation:** DCF + relative valuation (P/E, EV/EBITDA multiples)
6. **Sensitivity Analysis:** Vary WACC (±1%), growth (±2%), test robustness
7. **Report:** BUY/HOLD/SELL recommendation with target price

**Real Example (Hypothetical - Asian Paints):**

- Current Price: ₹2,800
- Intrinsic Value (DCF): ₹3,200
- Target Price (12-month): ₹3,400 (+21% upside)
- **Recommendation:** BUY

### For Investors

**Simplified DCF for Stock Screening:**

- Focus on high-quality businesses (ROCE >20%, low debt)
- Use 5-year projections (not 10 - too uncertain)
- Conservative assumptions (lower growth, higher WACC)
- Margin of safety: Buy only if >30% undervalued

**See [IMPLEMENTATION_GUIDE.md](../IMPLEMENTATION_GUIDE.md#module-13-financial-modelling)**

## 📊 Quick Reference

### Excel Color Coding (Industry Standard)

| Color     | Meaning                      | Example                  |
| --------- | ---------------------------- | ------------------------ |
| **Blue**  | Hardcoded inputs/assumptions | Revenue growth = 10%     |
| **Black** | Formulas/calculations        | = B5 × (1 + growth_rate) |
| **Green** | Links from other sheets      | = Balance_Sheet!B10      |

### Common Assumptions (Benchmark Ranges)

| Assumption            | Conservative   | Base    | Aggressive   |
| --------------------- | -------------- | ------- | ------------ |
| **Revenue Growth**    | 5-8%           | 10-12%  | 15-20%       |
| **EBITDA Margin**     | Current - 1%   | Current | Current + 2% |
| **Capex (% Revenue)** | 5-7%           | 3-5%    | 2-3%         |
| **Working Capital**   | 15-20% revenue | 10-15%  | 5-10%        |
| **Terminal Growth**   | 3% (GDP)       | 4%      | 5% (risky)   |
| **WACC**              | 12-15%         | 10-12%  | 8-10%        |

### Circular Reference Issue (Debt-Interest Loop)

**Problem:** Interest depends on debt → Debt depends on cash → Cash depends on interest (circular!)

**Solution in Excel:**

```
Enable Iterative Calculation:
File → Options → Formulas → Enable iterative calculation
Max iterations: 100
Max change: 0.001
```

## ⚠️ Common Mistakes

1. **Not balancing the Balance Sheet:** Assets ≠ Liabilities + Equity (integration errors)
2. **Hardcoding values:** Using "=1500" instead of referencing assumption cell
3. **Overly optimistic assumptions:** 30% revenue growth for 10 years (unrealistic)
4. **Ignoring working capital:** ΔWC can be 20-30% of FCF (material impact)
5. **Using book value of debt:** Should use market value for WACC
6. **Terminal value >80% of valuation:** Model too sensitive to terminal assumptions
7. **Not checking for errors:** #REF!, #DIV/0!, circular refs without iteration enabled
8. **Copy-pasting formulas:** Breaking cell references (use absolute $refs)
9. **No sensitivity analysis:** Single-point estimate = false precision
10. **Not understanding the business:** Garbage assumptions in = garbage value out
