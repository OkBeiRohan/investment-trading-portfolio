## 📖 Overview

Fundamental Analysis is the cornerstone of long-term investing. This module teaches you how to evaluate a company's intrinsic value by analyzing its financial statements, business model, competitive advantages, and growth prospects.

You'll learn to read annual reports like a professional analyst, understand the three critical financial statements (P&L, Balance Sheet, Cash Flow), calculate and interpret financial ratios, and perform equity research using DCF (Discounted Cash Flow) models. This module transforms raw financial data into actionable investment insights.

Unlike technical analysis which focuses on price charts, fundamental analysis answers the question: "Is this company worth buying at the current price?" It's essential for anyone pursuing value investing, growth investing, or building a long-term equity portfolio.

## 🔑 Key Concepts

### The Three Financial Statements

| Statement                  | Purpose                                   | Key Metrics                                 |
| -------------------------- | ----------------------------------------- | ------------------------------------------- |
| **P&L (Income Statement)** | Shows profitability over a period         | Revenue, EBITDA, Net Profit, EPS            |
| **Balance Sheet**          | Snapshot of assets/liabilities at a point | Total Assets, Debt, Equity, Working Capital |
| **Cash Flow Statement**    | Actual cash movements                     | Operating CF, Free Cash Flow, CapEx         |

### Essential Financial Ratios

**Profitability Ratios:**

- ROE (Return on Equity) = Net Profit / Shareholder Equity
- ROCE (Return on Capital Employed) = EBIT / Capital Employed
- Net Profit Margin = Net Profit / Revenue

**Leverage Ratios:**

- Debt-to-Equity = Total Debt / Shareholder Equity
- Interest Coverage = EBIT / Interest Expense

**Liquidity Ratios:**

- Current Ratio = Current Assets / Current Liabilities
- Quick Ratio = (Current Assets - Inventory) / Current Liabilities

### DCF Valuation Framework

```
Intrinsic Value = Σ (FCF_t / (1 + WACC)^t) + Terminal Value / (1 + WACC)^n

Where:
- FCF = Free Cash Flow
- WACC = Weighted Average Cost of Capital
- Terminal Value = FCF_n × (1 + g) / (WACC - g)
```

## 💡 Practical Applications

### For Traders

While primarily for long-term investors, traders use:

- **Earnings reports** for swing trades (pre/post earnings volatility)
- **Sector rotation** based on macroeconomic cycles
- **Event-driven trading** (mergers, acquisitions, dividend announcements)

### For Investors

- **Value investing:** Find undervalued stocks with P/E < sector average, high ROE
- **Growth investing:** Identify companies with revenue CAGR >20%, expanding margins
- **Dividend investing:** Filter stocks with dividend yield >3%, payout ratio <50%
- **Quality screening:** Companies with ROE >15%, Debt/Equity <0.5, consistent cash flows

## 📊 Quick Reference

### Investment Checklist (10-Point Due Diligence)

| #   | Criterion               | Benchmark                            |
| --- | ----------------------- | ------------------------------------ |
| 1   | **ROE**                 | >15% (sustainable)                   |
| 2   | **Debt-to-Equity**      | <0.5 (capital-light) or <2.0 (banks) |
| 3   | **Interest Coverage**   | >3x (safe debt servicing)            |
| 4   | **Current Ratio**       | >1.5 (liquidity buffer)              |
| 5   | **Operating Cash Flow** | Positive & growing                   |
| 6   | **Revenue CAGR (5Y)**   | >12% (outpacing GDP)                 |
| 7   | **Net Profit Margin**   | >10% (pricing power)                 |
| 8   | **Promoter Holding**    | >50% (skin in the game)              |
| 9   | **Dividend Payout**     | 20-40% (balance growth & returns)    |
| 10  | **Market Cap**          | >₹500 Cr (liquidity)                 |

### Red Flags to Avoid

| Red Flag                            | Implication               |
| ----------------------------------- | ------------------------- |
| Declining profit margins            | Losing competitive edge   |
| Rising debt with flat revenue       | Poor capital allocation   |
| Negative operating cash flow        | Earnings manipulation     |
| Frequent related-party transactions | Governance issues         |
| Auditor qualifications              | Accounting irregularities |
| Falling promoter holding            | Lack of confidence        |

## ⚠️ Common Mistakes

1. **Ignoring cash flow:** Companies can report profits but run out of cash (creative accounting)
2. **Not adjusting for one-time items:** Exceptional gains/losses distort true performance
3. **Using standalone financials:** Always check consolidated (includes subsidiaries)
4. **Comparing across sectors:** Banks vs IT have different normal D/E ratios
5. **Overweighting P/E ratio:** Low P/E can be a value trap (declining business)
6. **Ignoring management quality:** Good business + bad management = disaster
7. **Not reading footnotes:** Critical disclosures hidden in fine print
8. **Recency bias:** Extrapolating last 2 quarters into perpetuity
9. **Ignoring working capital:** Growing sales but trapped cash in receivables
10. **Not stress-testing assumptions:** DCF is garbage-in-garbage-out (WACC, growth rate)
